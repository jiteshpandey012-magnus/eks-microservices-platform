# Production Microservices Platform on Kubernetes

A production-style microservices application built using Docker, Kubernetes, and MySQL.

This project demonstrates how multiple services communicate inside a Kubernetes cluster while using persistent storage, containerized workloads, rolling deployments, and service discovery.

---

## Project Goals

- Learn Docker
- Learn Kubernetes
- Build production-style microservices
- Deploy using Kubernetes manifests
- Demonstrate service-to-service communication
- Implement persistent storage
- Showcase DevOps skills for portfolio
